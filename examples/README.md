# Standalone matching example

Run `python3 examples/matching_demo.py` from the repository root.

This newly written educational example demonstrates paired OR branches, a shared tanker requirement, unknown evidence, and approved/current eligibility. It uses a hand-authored plan shaped like parser output. It does not call an LLM or reproduce the full production schema, rank ontology, or matching engine.

All five candidate records are synthetic. `tanker` is intentionally simplified; real vessel subtype semantics require a richer domain catalog.
